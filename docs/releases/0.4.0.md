# SharedServer 0.4.0

SharedServer now provides an offline desktop/mobile workspace while keeping its existing API, CLI, permissions, and login-free defaults.

- Responsive desktop columns, tablet tabs, and mobile file cards with a persistent download action and wrapping filenames.
- System/light/dark themes, inline SVG icons, local QR generation, search, sorting, selection, and safe text/image previews.
- Upload queue with progress, cancellation and explicit retry; shared-text statistics, shortcuts, copy fallbacks and draft protection.
- Correct failed-directory retry targets; visible keyboard focus after navigation and menu actions; persistent folder errors and duplicate-submit protection; named upload progress and reliable toast pauses.
- Packaged local assets and licenses, with four Chromium regression suites in CI. No external CDN, fonts or runtime telemetry.

Three independent UI skill review rounds verified the usability fixes. Local validation covers 57 Python tests, 72 UI/permission/authentication cases, browser interaction regressions and built-wheel checks. Remote CI must pass before publication.

Physical iOS/Android devices, mobile keyboards, real 200% browser zoom, and complete manual screen-reader testing remain unverified. Browser viewport/touch emulation is not physical-device certification.

Upgrade:

```sh
pipx upgrade sharedserver
# or
python -m pip install --upgrade sharedserver
```
